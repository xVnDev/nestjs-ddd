# Security Policy

## Supported versions

| Version | Supported |
| :------ | :-------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please report vulnerabilities privately to security@example.com. Do not open public issues.

## Response timeline

We aim to acknowledge reports within 5 business days.

## Disclosure policy

Coordinated disclosure after a fix is available.

## Dependency update cadence

Dependencies are reviewed regularly; security updates are applied promptly.

## Compliance targets

ISO 27001:2022 / OWASP ASVS 4.0 L2 / HIPAA §164.312 / GDPR Art. 32.

CI security thresholds may only be suppressed with documented approval.
